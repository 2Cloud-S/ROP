# Rise of the Plants (ROP)

## User Experience & Design System

Version: 1.0

Purpose:

Define the complete visual language, interaction system, navigation patterns, animation philosophy, accessibility requirements, and mobile-first design standards for Rise of the Plants.

This document is the source of truth for all UI and UX decisions.

---

# 1. Design Philosophy

ROP should feel like:

* A magical botanical adventure
* A collectible creature game
* A living storybook
* A premium mobile game

It should NOT feel like:

* A SaaS dashboard
* A productivity app
* A corporate website
* A generic admin panel

---

# 2. Emotional Design Goals

The UI should evoke:

### Wonder

Players should feel they are discovering something magical.

---

### Growth

Progress should always be visible.

---

### Warmth

The interface should feel welcoming.

---

### Discovery

Every screen should invite exploration.

---

### Delight

Interactions should feel rewarding.

---

# 3. Visual Direction

Primary Inspiration:

Creature collection games.

Secondary Inspiration:

Botanical illustrations.

Tertiary Inspiration:

Fantasy field journals.

---

# 4. Art Direction

Visual Style:

### Semi-Stylized

Not realistic.

Not cartoonishly childish.

---

### Organic

Rounded shapes.

Natural curves.

Soft edges.

---

### Handcrafted

UI should feel designed by explorers and botanists.

---

# 32. UI Anti-Patterns

Do NOT build:

Tiny text

Crowded screens

Deep navigation trees

Multi-step forms

Dashboard-style layouts

Long settings pages

---

# 33. Design Success Criteria

The UI succeeds when:

* Players understand the game immediately.
* Progress is visible at all times.
* Evolution feels exciting.
* Codex feels valuable.
* AR feels magical.
* Mobile experience feels premium.

If a judge can open the game and feel curiosity, growth, and wonder within 30 seconds, the design system has achieved its goal.
