# Rise of the Plants (ROP)

## Technical Requirements Document

Version: 1.0

Project Type: Web-First AR Collection Game

---

# 1. Purpose

This document defines the technical architecture, implementation strategy, data models, system requirements, and engineering standards for Rise of the Plants (ROP).

This document serves as the technical source of truth for implementation.

---

# 2. Technical Goals

The system should:

* Be deployable through Replit
* Use Sanity as the content backend
* Be mobile-first
* Support AR experiences
* Remain simple enough for Buildathon development
* Demonstrate strong structured content usage

# 6. Sanity Architecture

Sanity is the source of truth for all game content.

Player-specific progress should NOT be stored in Sanity.

Sanity powers:

* Plant Species
* Evolution Paths
* Tasks
* Rewards
* Codex Entries
* Lore
* Rarity Definitions

---

# 9. GROQ Query Layer

All game content must be queried dynamically.

---

## Species Query

```groq
*[_type == "plantSpecies"]
```

---

## Species By Slug

```groq
*[
  _type == "plantSpecies"
  && slug.current == $slug
][0]
```

---

## Codex Entries

```groq
*[_type == "encyclopediaEntry"]
```

---

## Tasks

```groq
*[_type == "task"]
```

---

## Evolutions

```groq
*[_type == "evolutionPath"]
```

# 23. Definition of Done

The technical implementation is complete when:

* Sanity content powers the game world
* Growth system functions
* Evolution system functions
* Collection system functions
* Codex displays dynamic content
* Battle system functions
* AR viewer functions
* Mobile experience works
* Application deploys successfully

without critical bugs.

At that point Rise of the Plants is considered technically complete for Buildathon submission.
