# SANITY_SCHEMAS.md

# Rise of the Plants (ROP)

## Sanity Schema Implementation Guide

Version: 1.0

Purpose:

Define the exact schema structure, validation rules, references, Studio organization, and content population requirements for Rise of the Plants.

This document is implementation-focused and should be used directly by Replit Agent when building the Sanity Studio.

---

# 1. Sanity Version

Required:

Sanity Studio v3+

Use modern APIs:

* defineType()
* defineField()
* defineArrayMember()

Do not use legacy schema patterns.

# 4. Plant Species Schema

File:

plantSpecies.ts

Purpose:

Primary creature definition.

Every collectible plant originates here.

---

## Schema Definition

```typescript
import { defineType, defineField } from "sanity"

export const plantSpecies = defineType({
  name: "plantSpecies",
  title: "Plant Species",
  type: "document",

  fields: [
    defineField({
      name: "name",
      title: "Name",
      type: "string",
      validation: Rule => Rule.required()
    }),

    defineField({
      name: "slug",
      title: "Slug",
      type: "slug",
      options: {
        source: "name"
      },
      validation: Rule => Rule.required()
    }),

    defineField({
      name: "rarity",
      title: "Rarity",
      type: "reference",
      to: [{ type: "rarityDefinition" }]
    }),

    defineField({
      name: "description",
      title: "Description",
      type: "text"
    }),

    defineField({
      name: "loreExcerpt",
      title: "Lore Excerpt",
      type: "text"
    }),

    defineField({
      name: "habitat",
      title: "Habitat",
      type: "string"
    }),

    defineField({
      name: "attack",
      title: "Attack",
      type: "number"
    }),

    defineField({
      name: "defense",
      title: "Defense",
      type: "number"
    }),

    defineField({
      name: "health",
      title: "Health",
      type: "number"
    }),

    defineField({
      name: "evolutionStage",
      title: "Evolution Stage",
      type: "number"
    }),

    defineField({
      name: "image",
      title: "Main Image",
      type: "image"
    }),

    defineField({
      name: "gallery",
      title: "Gallery",
      type: "array",
      of: [{ type: "image" }]
    }),

    defineField({
      name: "primaryColor",
      title: "Primary Color",
      type: "string"
    }),

    defineField({
      name: "discoveryHint",
      title: "Discovery Hint",
      type: "text"
    })
  ]
})
```

# 11. Validation Rules

All species require:

* Name
* Slug
* Description
* Rarity
* Image

All encyclopedia entries require:

* Plant reference
* Lore

All evolution paths require:

* Source plant
* Target plant
* Required level

---

# 12. Query Support Requirements

The schemas must support:

* Species listing
* Species detail pages
* Codex pages
* Evolution chains
* Task loading
* Reward lookups

without requiring schema changes.

---

# 13. Definition of Done

The Sanity implementation is complete when:

✓ Studio runs successfully

✓ Schemas deploy successfully

✓ Species can be created

✓ Evolution chains can be created

✓ Lore entries can be created

✓ Tasks can be created

✓ Relationships resolve correctly

✓ GROQ queries return structured data

✓ New content can be added without code changes

At that point the Sanity content layer is considered production-ready for the Rise of the Plants Buildathon MVP.
